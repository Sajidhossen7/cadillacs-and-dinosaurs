# Cadillacs & Dinosaurs: Xenozoic Rampage (2513 AD)

A 2.5D arcade beat-'em-up tribute to the 1993 Capcom CPS-1 classic **Cadillacs and Dinosaurs**, built with HTML5 Canvas and a procedural CPS-1 / QSound-inspired WebAudio synthesizer.

## Features
- **4 Playable Heroes**:
  - **Jack Tenrec** (*Spiral Volcano Upper* — Balanced Xenozoic mechanic)
  - **Hannah Dundee** (*Flash Cyclone Kick* — High-speed tracker & +25% weapon damage)
  - **Mustapha Cairo** (*Tornado Flip Kick* — Aerial engineer with signature horizontal flying dropkick)
  - **Mess O'Bradovich** (*Seismic Lariat Crash* — Heavyweight powerhouse brawler)
- **Driveable 1953 Cadillac Eldorado V8**: Plow through poacher gangs, honk the dual-tone horn, and fire twin hood-mounted guns on Stage 2 or summon an air-drop anytime with `U` / `V`.
- **Dynamic Dinosaurs (Calm vs. Enraged)**: Encounter **Velociraptors ("Zeke")**, **Triceratops ("Mack")**, and **Pteranodons ("Shivat")**. Provoking a calm dinosaur turns it crimson and causes it to attack both Poachers and Players!
- **Arcade Arsenal & Pickups**: `.44 Revolver`, `Riot Shotgun`, `M16 Assault Rifle`, `Rocket Launcher`, `Dynamite Bundle`, `Spiked Club`, `Hunter Bowie`, and `Cadillac Radio Transmitter`—plus throw empty firearms at enemies when ammo runs out.
- **3 Multi-Wave Stages & Boss Fights**:
  1. *Stage 1: City in the Sea* (Boss: **Vice Terhune**)
  2. *Stage 2: The Butcher's Highway* (Boss: **The Butcher**)
  3. *Stage 3: Fessenden's Bio-Lab* (Final Boss: **Dr. Simon Fessenden**)

## Controls
| Action | Keys |
| :--- | :--- |
| **Move (8-Way)** | `W` `A` `S` `D` or `Arrow Keys` (or Gamepad) |
| **Sprint / Dash** | Double-tap `Left` or `Right` |
| **Attack / Shoot / Pick Up** | `J` or `Z` |
| **Jump / Jump Kick** | `K`, `X`, or `Space` |
| **Special Crash Attack** | `L`, `C`, or `J + K` |
| **Summon 1953 Cadillac V8** | `U` or `V` |
| **Insert Coin / Extra Life** | `5` or `Enter` |

## Run Locally
Double-click `start-game.bat` or open `index.html` in any modern web browser.
